## Purpose

让"全部"视图把分散在各来源的同类资产聚合成一张可读清单，来源边界用分段表达而不是导航层级。

## ADDED Requirements

### Requirement: 按来源分段聚合

"全部"视图 SHALL 按来源分段：全局适用段在前，各项目段按项目名稳定排序在后；无资产的项目 MUST NOT 产生空分段。每个分段标题 MUST 显示来源名称与数量，视觉层级沿用 source-distinction 的分段语言。

#### Scenario: 段序固定

- **WHEN** 用户在"全部"视图浏览任意类型
- **THEN** 全局适用段恒在最前，项目段顺序按项目名稳定，不随筛选或排序变化

#### Scenario: 空来源不产出空段

- **WHEN** 某项目在当前筛选条件下无匹配资产
- **THEN** 该项目的分段整体不出现，不显示空标题

### Requirement: 段内列表契约

筛选、稳定名称排序与分页 MUST 在每个分段内独立生效；所有分段共享同一列网格（含 Agent 固定分列）；筛选、排序或每页数量变化后回到第 1 页的契约不变。分页计数 MUST 以全部聚合结果为基数。

#### Scenario: 跨段排序不越位

- **WHEN** 用户切换名称升/降序
- **THEN** 每个分段内部按新方向排序，资产不跨段移动

### Requirement: 同名资产跨来源共存

不同来源的同名资产 SHALL 作为各自独立的资产行同时出现在对应分段中，不做合并、去重或覆盖暗示；其各自的状态、路径与 Agent 启停投影独立呈现。

#### Scenario: 同名指令并列

- **WHEN** 项目与全局各有一个 `AGENTS.md`
- **THEN** 两者分别出现在项目段与全局适用段，行内来源 badge 可区分，选择其中一个只影响该资产
