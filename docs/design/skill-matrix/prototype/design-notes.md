# Skills 使用矩阵设计说明

2026-10-14，沿用用户选定的项目 × Agent 矩阵，以及「来自全局」直接勾选／取消勾选的交互。本轮增加项目 Codex 启动入口及 OpenCode 项目原生排除；其他视觉方向保持不变。

矩阵区分已保存配置和变更草稿。取消全局来源的勾选仅在当前项目停用；预览、模拟应用后才改变样例。换项目保留草稿，恢复勾选移除项目排除并重新计算继承。

Codex 单元显示「启动入口生效」。项目头部的启动按钮打开对话框，展示完整路径及已保存排除项；当前项目有草稿时阻止启动，其他项目草稿不影响。对话框提供缺失 CLI、计划变化与重新读取的演示。启动为模拟，不打开真实终端。

OpenCode 常规项目单元可操作；frontend-design 的项目 OpenCode 单元是角色精细权限限制样例，可查看原因，不声称通用开关覆盖所有角色。

已批准原型包含早期探索的组合等样例；正式产品能力以仓库产品说明为准。正式 App 截图及真实文件／CLI 证据在仓库矩阵设计入口与验收记录中分别保存。本原型不检测文件、Agent 版本、真实会话或权限。
