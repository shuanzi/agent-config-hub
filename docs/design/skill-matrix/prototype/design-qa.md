# 项目排除增量的设计 QA

基准为已批准矩阵及直接复选框交互。本轮核对项目一排除与项目二保持继承、恢复继承、Codex 启动说明、本项目草稿阻止启动、缺失 CLI、计划变化和重新读取。

原型模型测试验证模拟状态；正式 App 的前端、浏览器、Tauri 新进程回读与 Codex CLI 检查分别记录在仓库验收产物中。原型的模拟成功提示不作为真实能力证据。

正式组件保持既有壳层、品牌标识、表格、颜色与 FocusedDialog，新增按钮与说明集中于项目矩阵。归档预览覆盖桌面排除／恢复／预览、启动对话框，以及 390px 的单 Agent、启动阻止和角色限制。截图使用真实编码和像素尺寸清单，并由仓库文档检查器验证。
