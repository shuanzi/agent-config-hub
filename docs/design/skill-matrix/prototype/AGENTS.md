# Skills 矩阵原型维护

通用协作与验证规则遵循仓库根 [AGENTS.md](../../../../AGENTS.md)。本目录是矩阵表面的独立模拟设计源，职责见[矩阵设计入口](../README.md)；使用自身的依赖锁文件，不并入正式 App。需要预览时复用或启动本原型的本地服务器。

## 本原型的交互约定

用户于 2026-10-14 要求将“来自全局”的“跟随”操作改为直接勾选／取消勾选。矩阵中的使用状态统一使用原生复选框；来源文字独立保留。勾选表示当前范围使用，取消来自全局的勾选表示仅在本项目停用，不能改动全局配置或其他项目。重新勾选恢复使用，不先打开选项弹窗。未核对的原生停用能力保留原状态、禁用该复选框，并通过邻近说明入口解释原因。此约定只适用于这份模拟设计原型。

2026-10-14 用户批准 Codex 项目启动入口：项目列标明仅经此入口生效，启动对话框使用已保存排除项，当前项目草稿阻止启动。OpenCode 项目排除使用原生权限；角色覆盖等限制明确显示。原型只模拟，不启动真实进程。所选布局不重新设计，设计源与预览清单同步更新。

## 构建能力

保留 `.openai/hosting.json`、`worker/index.js`、`scripts/prepare-sites-build.mjs` 和 `tests/sites-worker.test.mjs`，以支持已有的 Sites 交接能力。修改相关文件后先运行 `npm run build`，再运行 `npm run test:sites`，检查 `dist/client/index.html`、`dist/server/index.js` 和 `dist/.openai/hosting.json`。本次目录整理不执行发布或部署。
