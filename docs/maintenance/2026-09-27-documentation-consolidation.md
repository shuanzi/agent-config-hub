## 核对中发现的实质差异

- 旧固定 resolver 的统一全局适用性已不对应三类资产的读取集合：Skills 项目页显示已投放全局项，AGENTS.md 项目页包含全局文档，原生 Subagents 只扫描本项目。现行文档写明事实，不宣称运行时加载。
- 项目改绑新增 Skill 投放／原生状态保护；全局 override 则不搬迁原生定义，不能把二者当成同一种迁移保证。
- 旧指令预设、CLAUDE.md 双文档、Subagent 四 Agent 投影、通用 Gateway 和转换模型已替代；不把历史条款转成未授权待办。
- ADR 保留原理由，增加当前适用性；发布、加密快照与旧性能预算没有实现证据，均明确标注。
